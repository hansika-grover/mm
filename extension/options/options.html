Where extracted asset dumps are POSTed. Default is the local hub. If you point this at another host, that host must be added to the extension's host_permissions.
Tags every dump so the hub knows which machine/profile it came from (used when many agents report in).
When auto-run is on, the extension re-scrapes at most once per this many minutes per profile, so opening several Facebook tabs won't hammer Graph.
